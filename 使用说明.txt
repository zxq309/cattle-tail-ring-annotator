COWMATA 3.3.1 九轴与多视角标注工作台
先整理数据 → 再标注保存 → 最后复核导出。关于/帮助 → 新手图文教程：查看当前版本实际操作截图。

启动先检查更新，有新版自动下载安装，成功重开后才能标注；直接更新到最新版，不逐个安装中间版本。检查或更新失败时停留提示窗口，可重试或退出。启动检查不受此前关闭自动更新的设置影响。带更新器的安装版支持原位置自动更新；源码/便携副本需手动安装下载的新版。

标注常用操作
1. 打开包含“数据工程”的牧场批次文件夹。九轴先就绪，再自动显示对应录像；横幅出现“工程加载成功”表示本份可以使用，并非全部 842 段录像已经索引。
2. 底部“加载记录…”可查看和复制完整记录。正常关闭加载窗口会取消后台任务，失败或取消的新工程清理本次临时索引；已有标签、成功工程及原始数据保留。
3. 每个视角下方都有进度条，可点击位置或拖动后松开定位。显示本段经过时间/总时长；联动时九轴及其他视角一起定位。较远跳转可输入与视频共用时间基准的完整日期时间。
4. 1×/2×/4×使用主视角解码时钟。监控原始封装首次播放按需准备当前片段的无重编码缓存，上限 8 GiB，循环淘汰旧缓存；暂停核对仍读取原片精确帧。
5. 左侧蓝色“正在标注”、橙色“未完成”、灰色“未开始”、绿色“已完成”。切换九轴自动保存，返回恢复位置；点击“完成本份…”或 Ctrl+Enter 明确确认保存和完成状态。
6. 关闭工程窗口时选择“保存并退出”“不保存本次改动并退出”或“返回继续标注”。自动保存每 5 秒检查改动，切换时也保存；不保存退出仅放弃尚未写盘的改动，已经自动保存的内容仍保留。
7. 改错标签：重新打开原数据工程，左侧选择原记录，在下方标注列表选中一条，点“编辑”修改标签/起止时间/备注，或点“删除”。修改后自动保存，已完成记录恢复为未完成，改过的真值需重新复核；删除可撤销。
8. “打开历史标注回看”是只读回看窗口。要修改工程标签，请回到主窗口打开原工程。详见 docs/release-321-validation.md。

本次修复：播放准备复用；动作状态明确；标注列表可独立微调起止时间。

以下为完整功能说明，图文操作说明书与 3.3.1 安装包同步更新。

一、启动
安装版运行 Setup.exe，安装后从开始菜单打开 COWMATA。免安装版完整解压后双击 COWMATA.exe（START_ANNOTATOR.bat 也保留）。不要在压缩包内直接运行。
本包面向 Windows 10/11 64 位，自带 Python、Qt、VLC、FFmpeg 和 OCR 模型。
不需要安装 Python、配置 PATH、删除旧 .venv 或联网下载模型。
软件和数据不必放在同一个目录。整个软件文件夹可搬移。

二、先整理数据，或打开现有工程
顶部“数据整理”可审查、归类和查看异常报告。添加九轴文件/根目录、多视角文件/根目录，视角统一为视角01～视角08。
九轴设备目录须为“完整12位设备编号-牛耳标号-现场记号”，例如 546C50CA07D5-21100-10。
耳标保留前导零；现场记号允许数字、大小写字母及其组合，保留原样。数字可继续使用10、11，不必换一套编号。
名称缺项、顺序颠倒、短设备号或与JSON设备号不符时，先显示具体路径和建议，核对改名后再审查执行；有效原始九轴不会当作废料删除。
同设备跨日期再次佩戴属于复用，按每份记录的设备、牛号、记号和采集时间保存，不按设备号合并或删重。
先选择本批类别：正常健康、发情、孕早期、孕中期、孕晚期、产犊、疫病。孕期由人确认，所有类别都能自由标行为。
执行前核对移动预览；同卷直接剪切，跨盘拦截。无关杂项移入工程外隔离区；异常九轴、标签和绑定表保留。
九轴归入真实采集日期；视频按确认的单日/多日归档。任务可暂停、续接，进度与任务文件在软件数据目录中。
正在标注同一目录或父子目录时，先“保存并暂停当前工程”；其他工程可同步标注。
旧工程可直接打开，递归读取九轴和录像；旧名称异常仅提示复核，不丢弃已有标注。
九轴按元数据设备号选择，逻辑视角自动分组后由人工核对；软件不要求标签与录像同名，也不改名/搬动原片。
“标注工程”是软件生成的索引、同步及工作成果目录，请随工程备份，不要把它当作待加载的顶层工程。

三、打开工程与自动索引
点“打开工程”，选择包含现有九轴与录像的顶层目录；“素材”展开设备、九轴记录和视角选择。
每次打开核对整个目录，使用中监视变化并定期复查。新增文件稳定且能解析后进入索引。
首次识别时间戳需要时间；完成后未变文件直接复用，已识别内容可以先用。
新索引默认 RapidOCR 3.9.2 + PP-OCRv6_medium，本包已附离线权重并检查 SHA-256。
本次 OCR 算法升级会将旧自动索引排队复核；已有人工标签和双锚点校准保留。本算法已完成且文件未变时不重跑。也可对所选视频手动重新建立索引。
图片、说明、监控配套文件、未完成下载后缀不作为录像处理；非九轴 JSON 识别后忽略。
损坏的九轴或录像仍显示异常，不当作普通杂文件悄悄丢掉。
删除/移动/替换会提示，旧人工成果按内容身份保留，不转移给同名新文件。
疑似完全保持元数据的外部篡改，可运行“全文件内容核验”。
缺少视频时间时，进入“素材 / 时间核验”：四角识别、框选时间戳、读取其他位置、输入人工读数。
同一个物理相机跨批次保持同一个逻辑视角名；自动分组只是候选，可人工修改。
人工读数、同步关系和标注与可重建索引分开保存，请勿只备份 index.sqlite。

四、看九轴、看录像、标注
选九轴设备和记录，人工填写对应牛号；勾选需要的 1–8 个视角。
开发人员已确认 create_time 是设备开始采集时间，update_time 是服务器收到数据时间。
V2 按 create_time 加原始帧计时建立采集时间；旧协议保留兼容及估计时间提示。采集时间可以定位候选录像，但不替代相机人工同步。
先浏览录像也可记录动作草稿，不要求先从波形辨认事件。
九轴和视频分别定位到可确认的对应点，点“对齐”；再核对较远处的对应点。
两点之间才是已校准范围，范围之外、时间跳变区间和无法确认的动作保留草稿。
相机时钟不同，请在“工具 → 时间同步”菜单单独校准每个相机，而不是改视频时间戳。
用“开始 / 结束视频动作”或原协议快捷键记录区间；点事件一次记录。
动作跨小视频会继续，跨九轴记录使用同一事件组；不同牛号不能混为一个动作。
联动播放到九轴末尾时，后台查找同设备、同牛号、时间已校准且覆盖当前时刻的下一份。
只有唯一匹配才自动续接，视频位置、倍率和视角不变。未校准或多份重叠时提示人工核对。
关闭联动可取消自动续接。不会根据 create_time 硬拼连续采集时间。
覆盖提示检查整个工程而非只检查当前勾选视角；其他视角有画面会列出可用视角。
索引未完成、录像时间待核验、九轴同步未确认时，不会断言后续没有录像。
按当前校准确实超出全部已确认录像范围时，提示后续九轴暂不具备录像真值，不自动标为正常。
可编辑标签、边界、备注；修改边界/同步后需要回看并补充画面证据、再次确认。
确认真值前请核对牛号、视频内容与前后同步点。程序不自动判断牛行为。
导出的未确认/未观看样本不是负样本，逐样本表 reviewed_any=0 表示未复核。
导出保留真实采样时间、缺口、来源内容身份、参考时间、同步版本和视频证据。

五、播放与性能
A 观察（默认）：大主视频 + 可滚动辅视角 + 底部九轴。
B 多视角：网格同时显示所选 1–8 路 + 底部九轴。
C 波形：大波形 + 画中画；拖动画中画标题移动，不遮挡波形工具栏/标签轨道。
三种布局共用现有播放器，切布局不重新打开文件，不改变参考时间和倍率。
九轴按加速度、角速度、磁场分组；悬停显示最近原始样本值与单位，缺口显示“—”。
波形滚轮缩放，Shift 拖动平移，普通拖动选择区间；“视图”可显示完整记录。
标签轨道独立于波形；虚线标注为待复核，不代表已确认真值。草稿位于“标注列表”。
详细编辑、确认、补证据、删除在“标注列表”侧栏，常用命令在顶部菜单中。
“视图 → 界面与播放设置”可调底部波形比例、画中画大小及严格同步/兼容缓存。
该设置中可开关毛玻璃观感；视频和波形不做透明模糊，系统不支持 Mica 时正常回退。
播放条下拉框可选“八路全速”或“主路优先 · 辅路预览”。实际路数取决于勾选视角。
若多路卡顿，优先选主路优先：主画面原片全速，辅路最多两个后台低频预览任务。
辅路显示预览真实时间与时间差，不能作为当前真值；点击切为主视角后加载该时刻原片。
暂停后所有勾选视角恢复原片精确帧，可用于核验。预览不是八路原画全速的替代承诺。
布局、分组和面板状态随工程保存。输入牛号/时间时不会误触发单字母或数字快捷键。
各视角按同一参考时刻定位，自动接下一小视频；没有录像的时间明确留空，不显示旧帧。
单击视角切主视角/声音，双击画面或“放大”放大单路，Esc 返回；Alt+1…8 可快速换主视角。
Space 播放/暂停，左右箭头移动 0.1 秒，[ 和 ] 逐帧，Alt+1…8 选主视角。
暂停画面使用原片实际 PTS 提取，最多两路并发；多路暂停可能需短暂等待。
普通 MP4 直接播放。异常监控 PS（即使后缀是 mp4）可勾选“监控兼容缓存”。
兼容缓存只重新封装当前/下一份工作文件，不重编码、不改原片，最多 8 GiB。
复杂 PTS 跳变会拒绝不可信缓存；可以浏览原片并人工核验。
1–8 路功能经过受控视频测试，但八路高分辨率 HEVC/高速播放仍受电脑性能影响。
暂停后核对精确画面再确认边界；高速播放的播放器时间读数不是逐帧真值。
出现缓冲可减少同时显示路数、降到 1 倍、启用兼容缓存，或切换软件解码后重开工程。

六、保存、安全和旧版
Ctrl+S 手动保存，平时约每 5 秒后台自动保存；关键动作立即保存。
自动保存单任务顺序写入，手动保存、关闭或切换工程会等旧写入完成，避免旧快照覆盖新标注。
保存失败会提示并阻止关闭/切换工程，先解决磁盘或权限问题。
另一窗口打开同一工程时只读；程序只读原视频/JSON，不删除、不改名、不转码原件。
旧单视频人工标注入口在“工程”菜单中，原标签协议和导入/导出保留。
模型训练及任意用户自备可执行权重不属于本便携标注包；已核对的 20260906 五类候选模型和依赖随包提供。
出现异常请保留 logs/annotator.log 和数据工程。验收范围与限制见 docs/workspace-acceptance.md。
算法验收见 docs/algorithm-phase1-acceptance.md；界面阶段验收与限制见 docs/ui-phase2-acceptance.md。
本版新增外观/性能的实测与限制见 docs/ui-performance-acceptance.md。
本版已接入独立历史回看、内置原始记录的单文件导出及 20260906 五类事件候选预测。验收范围见 docs/event-models-acceptance.md。
旧界面对比可使用命令参数 --workspace-ui classic。

七、标注输出：默认一个文件，不套导出子目录
“更多 → 工程 → 导出当前成果”保存一个 .标注.json，包含人工标签、视频草稿、来源身份、校准版本及相关录像索引快照。
默认在同一个标注 JSON 内置完整九轴原始 JSON 字节（含原有附加字段），不复制录像，不自动生成 CSV、逐样本表或小视频。文件名自带原记录名和短身份码，避免多设备重名。
文件可保存在桌面、移动硬盘、统一的“标注结果”目录等任意位置，不必跟录像的日期/设备目录一一嵌套。
再次覆盖同一个标注文件会保留一份 .bak 恢复副本；不会覆盖原始九轴、录像或其他记录的标注。
训练使用的多种 CSV、BORIS 等仍在“训练与兼容格式（批量导出）”中，只有主动选择才输出。
Ctrl+S 和自动保存仍保存到当前数据工程的“标注工程”内部；请整体备份该目录，不需要手工整理内部索引/版本记录。

八、独立回看与九轴小片段
“更多 → 工程 → 打开历史标注回看”或 Ctrl+Shift+O 选择标注 JSON，无须先加载当前九轴，不覆盖当前人工成果。
历史窗口为只读，可点击标签定位九轴和对应录像、播放、跨小视频、切主视角、单独放大、多画面查看。
九轴上拖选区间，再选“导出所选九轴片段（含标签）”，生成一个 .片段.标注.json，内含该段原始九轴帧和标签。有留存图片时，同级生成或复用一个“证据”文件夹，请一起复制。
片段不重采样，保留真实缺口、母文件身份及偏移；波形显示母文件时间。跨片段边缘的事件保留原始边界，不伪造截断真值。
片段只带九轴帧，不把温度/活动量等独立时间轴数据拉伸到片段中；原始完整数据不改。
a5 起完整标注文件内置原始九轴；小片段文件内置所选帧，两者没有母文件也能回看已携带的九轴。3.1.0 可在原录像离线时看已保存证据图；播放完整动作仍需访问原片。a4 及更早的引用式完整标注仍需原始九轴。
标签搬走不影响身份。数据工程整体搬家或改盘符后，历史窗口点“重新选择数据工程”。已重建索引的重命名原件按 SHA-256 找回。
未建立索引但保留原相对目录时，历史快照也可回溯相关录像；如果录像重命名且没有索引，请先用主窗口加载工程建立索引。
没有人工锚点时，可按设备 create_time 和帧计时定位候选录像；update_time 与文件名不作采集起点。设备时钟、单锚点/外推均不等于已核准同步。
旧“全部人工成果.json”和旧单视频工程 JSON 可读；缺失原件身份或同步信息时，只显示标签并提示补充，不猜配。
命令行也可直接打开：START_ANNOTATOR.bat --annotations "D:\标注结果\某份.标注.json" --project "D:\东一牛舍工程"
范围、证据和限制见 docs/annotation-history-acceptance.md。

九、新版候选模型（开箱即用，无需安装 Python/科学计算库）
“更多 → 标注 → 新版事件候选预测”选择版本和事件，默认按顺序扫描五类：起立、卧倒、排尿、抬尾、甩尾。
先核对当前牛号；这五个模型仅接受完整 V2 原始记录。私有旧版兼容运行库与新 GUI 隔离，最多两个逻辑 CPU，后台可取消，不修改系统环境。
双击候选定位九轴及对应视频；未同步时保持视频位置并提示。预测时间是大概发生点，不是事件边界；分数不是概率，未预测到也不能当负样本。
看录像后在九轴上重新拖选真实范围，再“所选九轴区间建视频草稿”。确认真值仍须通过牛号、同步及录像证据检查。候选、排除/未知状态、模型版本和来源身份随成果一起保存。
模型质量报告在候选窗口下方。换九轴/牛号/工程会取消旧任务并丢弃未保存结果；关闭候选窗口取消剩余任务。已保存候选保留，下次扫描相同来源和版本优先复用缓存。
需要流畅播放时可选“主路优先 · 辅路预览”；后台推理期间播放四路及以上会自动启用该保护（含独立历史回看），不会反复自动切回；任务结束可手动选择全速。预览不作到位真值，暂停后返回原片核验。旧版单视频/模型辅助代码和入口保留。
新增算法由维护者打包为新版本，不覆盖旧模型；不要自行替换任意 .pkl/.joblib。模型更新说明见 docs/event-models-acceptance.md。

十、截图留证与外部录像归档
确认真值后，可在留证窗口选一个代表时刻，每个选中视角提取一张原始分辨率图片。波形明显点仅作建议，需核对目标牛和代表时刻后保存。
图片只供人工回看，不输入九轴算法。缺失、时间不可信的视角会提示；看不清的画面不能冒充可靠真值。
保存成果时一起带走标注 JSON 和同级“证据”文件夹。历史窗口切换“留存证据图”，点击图片按原分辨率放大。
先复制完整录像到外部归档，再运行“更多 → 素材 → 录像归档副本核验”；逐文件 SHA-256 通过后仍须抽查播放、核对标签与证据完整性。软件不会自动删除录像。
保存归档记录后再次导出标签，以携带归档线索。用户随后可自行清理本机录像副本，但应保留原始九轴、标注工程及导出证据。详见 docs/evidence-archive.md。

十一、自动更新
安装版默认启动后及每 30 分钟检查 GitHub；发现新版本会提醒，可在后台下载，保存退出后在原位置升级。不会在标注时强退。
旧版没有更新器的客户，需要手动安装本版一次。此后维护者发布递增版本的 EXE、校验文件与更新清单，客户端即可自行发现。
断网仍可标注；软件关闭时不会接收实时推送。「帮助 → 关于 → 版本与更新」可手动检查、暂停下载或调整通道。详见 docs/client-updates.md。
