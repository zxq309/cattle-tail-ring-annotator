# COWMATA 3.4.1 纯净优化版

双击 `COWMATA.exe` 或 `START_ANNOTATOR.bat`。随包提供私有运行环境、播放器、FFmpeg、OCR 权重及事件模型。启动沿用原版的联网版本检查；进入工程后可离线标注。

本版数据目录为“牧场/类别/Motion、PPG、Video/真实日期”。在“数据整理”中选择本批类别、来源、视角和保存方式，先预览再归档。跨日文件按开始日存放，加载按实际覆盖时间匹配。

视频只以起始秒命名，例如`2026-08-03_12-34-56.mp4`。首选流内时间；OCR失败时仍采用流内时间，复核状态保留在工具内。索引保留原始精度用于九轴对齐。

设备目录支持“设备编号-耳标-现场标记”，也支持用户确认的倒序唯一五位耳标恢复；含歧义的记录保留待核对。PPG 当前预留目录及保存/导出字段，尚无解析器和波形。

请阅读根目录《使用说明.txt》和 [3.4 更新说明](docs/release-340.md)。早期版本教程仍用于通用标注操作，数据整理规则以 3.4 文档为准。

代码在 `cowmata_tailring`，回归测试在 `tests`。旧任务回放和恢复仍保留；一次性修改脚本及闲置生产代码已按用户二次确认清理。

3.4.1：修复下拉框空格播放、零时长区间和新标签选择；恢复标签轨道拖动与波形手柄，补充人工标签提示。见 [更新说明](docs/release-341.md) 和 [图文教程](docs/quick-start-illustrated.md)。
