# 旧标签到算法数据集

## 目录与类别

牧场目录下使用 `怀孕/孕早期`、`怀孕/孕中期`、`怀孕/孕晚期`、`产犊`、`发情`、`疫病`、`正常`。每个类别内沿用 Motion、Video、PPG 和标注工程。文件按实际开始日保存，跨日按覆盖时间加载。尚未确认孕期的既有怀孕资料保留原位置，不能自动分到孕晚期。

## 旧标签迁移

在数据归类子窗口点击“旧标签与算法数据集”。来源可逐行输入文件或目录；填写标签来源、原始九轴来源、资源或牧场目录，明确本批类别。先点“审查并预览旧标签”，核对匹配数与待核数，再执行迁移。

旧 CSV 和九轴原件保持不变。标注工程/annotations 是当前可编辑成果；标注工程/导出标注 是可独立回看的单文件成果；旧标签原件、迁移记录和待核原始保存来源及问题。产犊不按引产方式建子类别。露蹄、完全娩出及人工干预分别保留为点事件。

旧行为相对时间和源帧不变；新版绝对时间以真实首帧计时，旧绝对字段保存在原行中。出现牛号冲突、无匹配源、损坏九轴或未知时间时保留待核；绝不能拿另一头牛或目录日期补造时间。

## 日常标注后生成数据集

先 Ctrl+S 保存。打开“数据整理 → 从标注生成算法数据集”，逐行添加需要合并的类别工程，指定一个尚不存在的批次目录，例如牧场下的 `算法数据集/新批次`。输入来源不能包含输出目录。优先使用当前工程；旧导出快照不覆盖新编辑或删除。

如有历史算法数据集，选择包含 `02_数据集` 的旧事件识别目录。默认保留代理负样本为待核；确需沿用原训练方案时可显式勾选仅用于训练。源目录和旧数据集都不被覆盖。后台完成后打开结果目录。

| 输出 | 用途 |
| --- | --- |
| 原始JSON、sources.jsonl | 完整连续九轴及来源索引，原始内容不切窗 |
| events.jsonl、母标签.csv | 重叠母标签、绝对时间、类别、身份和复核状态 |
| cow-splits.json | 全部算法共享的按牛训练/验证/测试划分 |
| 事件识别/各行为 | 原算法维度的特征、训练输入、验证/测试候选和可用性报告 |
| 历史算法对齐 | 旧特征逐行对应新版来源与母标签，冲突不进训练 |
| 综合决策 | 连续活动量/温度输出、温度观测表、产犊 T0 与问题清单 |
| PPG | 后续通道与标注占位 |

## 训练与复核

先看各行为 `readiness.json`。起立使用人工支持的负样本；卧倒和抬尾可采用正例/未标注学习，U 不是评价真值。排尿和甩尾沿用历史代理负样本前需要明确选择。没有候选的人工事件仍保留在母标签与 unmatched_events.csv，不凭空添加模型候选。

在便携目录可使用 `runtime/python.exe -I -B scripts/train_mother_dataset.py --dataset "数据集目录" --head "起立" --output "新的研究模型.joblib"`。训练只使用 train 牛，模型仍需独立验证和阈值校准，不能自动替换随包模型。五个接口维度依次为 69、132、216、113、178。

综合决策离线回放明确标记 json_update_proxy 接收时间。温度样本时间沿用旧协议的包内中点估计并注明来源；活动量使用九轴真实计时。人工产犊标签单独用于评价，不作为算法输入。缺失、拒绝和预热不足不等于零风险，算法证据分数不是已校准产犊概率。
