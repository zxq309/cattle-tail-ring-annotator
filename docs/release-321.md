# COWMATA Annotator 3.2.1

2026-09-09 · Windows 10/11 x64 · 完整离线安装版

下载 **COWMATA-Annotator-3.2.1-Setup.exe** 即可安装。运行库、OCR 和五类已有模型均离线内置，无须配置 Python、VLC 或 CUDA 工具包。安装包 531,498,659 字节，约 507 MiB；安装文件约 1.56 GB。GitHub 自动生成的 Source code.zip 仅为源码，普通用户请选择 Setup.exe。

## 加载与播放

- 修复嵌套“数据工程/视角/批次”目录的相机混组与分辨率变化拆组，保留人工命名及原有校准。按当前九轴的实际时段优先搜索录像，不必等待整批录像扫描完才开始。
- 原来保存的视角无效或不覆盖当前时刻时，自动选择有画面的视角；九轴与实际原片帧就绪后明确提示加载成功。
- “加载记录…”显示最近 500 条完整消息，可以拉大、选择和复制。加载中正常关闭可取消后台任务；失败或取消的新工程清理本次可重建的临时索引，已有标签、成功工程、证据和原始文件保留。
- 每个视角都有常驻进度条和本段经过时间/总时长；点击或拖动松开定位，合并过期跳转请求。
- 优化 1×/2×/4×：主视角使用实际解码时钟，减少反复纠偏跳转。原始监控 PS 封装按需使用经时间校验的无重编码缓存，总上限 8 GiB；暂停标注仍直接读取原片精确帧。

## 保存、续标与改错

- 左侧用文字和颜色区分“正在标注、未完成、未开始、已完成”。切换记录自动保存标签和位置，选回时从上次位置继续；标了几条不会自动算整份完成。
- “完成本份…”或 Ctrl+Enter 提醒确认保存，可完成后继续下一份、保存退出或继续本份；联动到九轴末尾时也提醒处理。
- 关闭窗口可选择“保存并退出”“不保存本次改动并退出”或“返回继续标注”。自动保存的既有内容继续保留，不保存退出仅放弃尚未写盘的更改。
- 重新打开原数据工程，选择原九轴和下方标签，点击“编辑”修改类别、起止时间与备注，或“删除”。修改后保存，已完成记录恢复为未完成，改过的确认标签需重新复核；删除可以撤销。独立历史回看窗口继续只读。

## 验证

549 项本机自动测试通过、5 项可选环境测试跳过；完整离线包验证真实录像 OCR、五类模型运行、九轴历史片段与完整原始数据保存。独立目录验证安装及 EXE 启动，11,853 个安装文件全部通过 SHA-256 校验；卸载保留非软件文件。

366 份九轴、842 段录像的本机样本中，首次自动出画面约 10.8 秒，已有索引重开约 1.5 秒。三台相机各选一段原录像分别测试：暂停远跳约 0.2–0.5 秒，播放中远跳约 0.12–0.14 秒；1×/2×/4×画面持续更新，主路没有自行纠偏跳转。

以上是 RTX 2080 Ti 本机样本结果，并非三路同时 4×，也不是所有录像/硬盘的时延保证。未索引时段仍可能需要检索；未核准的同步和模型候选仍需人工复核。详见[发布前验证记录](https://github.com/zxq309/cattle-tail-ring-annotator/blob/v3.2.1/docs/release-321-validation.md)。

## 升级

带更新器的安装版可在“帮助 → 关于 → 版本与更新”检查，后台下载并校验，保存退出后升级。自动检查仍按启动及每 30 分钟执行，不会立即强退正在标注的软件。手动安装请选择新的软件目录，旧 3.2.0 发布保留。

附件 SHA-256 与 cowmata-update.json 供完整性和自动更新校验。基础操作仍可参考 [3.2.0 图文教程 PDF](https://github.com/zxq309/cattle-tail-ring-annotator/releases/download/v3.2.0/COWMATA-3.2.0-Quick-Start.pdf)，本次新增操作以上文为准。
